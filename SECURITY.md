# Security Policy

## Supported Versions

Only the latest minor version of `@sketch-ui/react` and `@sketch-ui/tokens` receives
security fixes.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities. Instead, email
security@sketch-ui.dev with:

- A description of the vulnerability and its impact
- Steps to reproduce (a minimal repro repo is ideal)
- Any suggested remediation

We aim to acknowledge reports within 3 business days and to ship a fix or mitigation
within 30 days for confirmed issues.
